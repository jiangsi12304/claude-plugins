# token-meter

Claude Code 插件：把**上下文用量、token 数和估算花费**画在提示框上方一条常驻横栏里，按模型分账，并在上下文快满时自动压缩。

用网关（`ANTHROPIC_BASE_URL` 指向自建/第三方网关）时，Claude Code 自带的 `/cost` 认不出 `global:…`、`cn:…` 这类模型的价目，于是花费基本是盲区。这个插件补上这块：**价目你自己填一次，之后每次对话都记账**。

## 功能

- **常驻横栏**：`ctx ███░░░░░░░ 32% 320k/1.00M · session $0.12 · today $0.86`。上下文条 10 格，超过 `warnAt`（默认 70%）转警示色；`working…` 在回合进行中显示。
- **上下文构成**：面板顶部列出上下文被什么占着——系统提示词、工具 schema、技能列表、消息等，各自多少 token、占窗口百分之几。新会话一开口就显示 5%–8% 正是这些固定开销（4 个插件 + 大量 skill 描述 + MCP 工具定义都会算进去），不是你的对话。
- **每模型账本**：面板里按模型列出输入 / 输出 / 缓存读取 token、估算花费、回合数。点 `price · set` 给某个模型填单价（`输入,输出`，每百万 token 美元），价格存进插件存储，跨会话保留。
- **未定价标记**：没有价目的模型显示 `unpriced` 而不是 $0.00——不假装免费。
- **缓存计价**：缓存读取按输入价的 0.1 倍、缓存写入按 1.25 倍计算（各家网关的通行倍率），所以缓存命中率高时账本不会虚高。
- **预算守卫**：上下文达到 `compactAt`（默认 85%）时自动调 `$.session.compact()` 压缩一次，同一百分比不会重复触发；`0` 关闭。压缩失败会写进面板状态行。
- **每日预算**：`dailyBudget > 0` 时，当天估算花费超线弹一次 toast。
- **跨会话日账**：最近 14 天的花费 / token / 回合数，存 `$.store`，面板底部按天列出。
- **命令**：`/tokens` 打开面板；点横栏上的 `session $x.xx` 也打开。

## 安装

```sh
claude --plugin-dir path/to/token-meter
```

或加进 `~/.claude/settings.json` 的 `env`：

```json
{ "CLAUDE_CODE_PLUGIN_DIRS": "path/to/token-meter" }
```

## 配置（`/config` 里的五行）

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `showBand` | boolean | `true` | 是否在提示框上方画计量横栏 |
| `compactAt` | number | `85` | 上下文百分比达到它时压缩一次；`0` 关闭 |
| `warnAt` | number | `70` | 从该百分比起上下文数字转为警示色 |
| `dailyBudget` | number | `0` | 每日估算花费上限（美元），超线提示一次；`0` 关闭 |
| `paneRows` | number | `22` | 面板内联时请求的高度（行） |

## 数据从哪来

- **上下文与 token**：`$.session.usage()` 的 `context.tokens` / `window` / `percent`，与状态行同源；回合进行中每 2 秒刷新一次。
- **每次花费**：`turn.complete` 事件的 `usage`（输入 / 输出 / 缓存读写，以及 API 报告的模型 id），按你填的价目换算。
- **引擎自己的花费**：`$.session.usage().cost.usd`，也画在横栏上；网关模型通常为 0，所以插件另算一份自己的账。

## 说明与限制

- 价格是**你自己填的**：插件不联网查价，也不猜。`input` 指每百万 token 的输入价，`output` 指输出价，按美元计。
- 缓存倍率（读取 0.1×、写入 1.25×）是通行做法，各家网关可能略有差异；如果你的网关计价不同，账本会有偏差。
- 只记主对话的回合；子代理的回合不计入（它们的消耗通常由父回合汇总）。
- 上下文守卫是「到达阈值压缩一次」，不是「持续压到阈值以下」：压缩后如果又涨回去，会再触发一次。
- 插件不发送任何网络请求，不读取任何文件；价目与日账只存在 `$.store` 里。

## 开发

```sh
claude plugin validate .   # 读清单和模块源码，报告会被拒绝的东西
claude plugin test .       # 跑 tests/ 下的 *.test.tsx
npx -p typescript@5 tsc -p .   # 类型检查
```

- `hooks/register.tsx`：全部逻辑（横栏、面板、记账、计价、守卫、日账）。
- `types/index.d.ts`：`$.state` 的值契约。
- `tests/meter.test.tsx`：横栏显示、打开面板、按价记账、未定价标记、填价并持久化、守卫触发与去重、关闭守卫、关闭横栏。
